| 의사결정 | 내용 |
|----------|------|
| ✓ 재고 흐름 방향 | Midas ERP → 쇼핑몰 (단방향). Midas가 재고 원천 |

| ✓ 개별 수정 용도 | 긴급 재고 조정, 오류 수정용. 다음 Midas 동기화 시 덮어씌워짐 |

## 재고 목록 조회

### 표시 항목

| 컬럼 | 설명 |
|------|------|
| 상품명 | 상품명 + 썸네일 |
| SKU | 재고관리코드 |
| 색상 | 옵션 색상 |
| 사이즈 | 옵션 사이즈 |
| 현재 재고 | 현재 재고 수량 |
| 상태 | 정상 / 저재고 / 품절 |
| 최종 수정 | 마지막 수정 일시 |

### 필터 옵션

- 상품별 / SKU별 보기
- 재고 상태 (전체 / 정상 / 저재고 / 품절)
- 카테고리 필터
- 검색 (상품명, SKU)

### 정렬 옵션

- 재고 적은 순 / 많은 순
- 최종 수정일 순
- 상품명 순

## 엑셀 업로드

### 업로드 형식

| SKU | 재고수량 | 비고 |
|-----|----------|------|
| KNC-BLK-M | 50 | |
| KNC-WHT-L | 30 | |
| KNC-NAV-S | 0 | 품절 |

### 처리 결과

| SKU | 재고수량 | 비고 | 처리결과 |
|-----|----------|------|----------|
| KNC-BLK-M | 50 | | ✓ 성공 |
| KNC-WHT-L | 30 | | ✓ 성공 |
| INVALID-SKU | 10 | SKU 없음 | ✗ 실패 |

### 업로드 플로우

```
1. 엑셀 파일 선택
2. 파일 검증 (형식, 필수 컬럼)
3. SKU 유효성 검사
4. 미리보기 표시 (성공/실패 건수)
5. 확인 후 일괄 반영
6. 결과 리포트 다운로드
```

## 개별 재고 수정

### 수정 방식

1. 목록에서 SKU 선택
2. 수정 모달 열기
3. 새 재고 수량 입력
4. 변경 사유 입력 (선택)
5. 저장

### 경고 메시지

> ⚠️ 개별 수정된 재고는 다음 Midas 동기화 시 덮어씌워집니다.

## API 명세

### GET /api/v1/admin/inventory

**Query Parameters**

| 파라미터 | 타입 | 설명 |
|----------|------|------|
| page | int | 페이지 번호 |
| limit | int | 페이지당 개수 |
| status | string | 재고 상태 (all/normal/low/out) |
| category | string | 카테고리 슬러그 |
| q | string | 검색어 (상품명, SKU) |
| sort | string | 정렬 옵션 |

### PATCH /api/v1/admin/inventory/{option_id}

**개별 재고 수정**

```json
{
  "stock_quantity": 100,
  "reason": "긴급 재고 추가"
}
```

### POST /api/v1/admin/inventory/bulk-upload

**엑셀 일괄 업로드**

```
Content-Type: multipart/form-data
file: inventory.xlsx
```

### GET /api/v1/admin/inventory/export

**엑셀 다운로드**

Response: `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`
