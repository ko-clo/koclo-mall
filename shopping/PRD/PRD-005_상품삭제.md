---

## 삭제 방식

**Soft Delete** 방식 사용:
- `is_deleted = true` 플래그 설정
- 실제 데이터는 삭제되지 않음
- 복구 가능

---

## 삭제 정책

| 조건 | 삭제 가능 | 처리 |
|------|----------|------|
| 미결제 장바구니 존재 | ✓ 가능 | 장바구니에서 '품절' 표시 |
| 미완료 주문 존재 | ✗ 불가 | "미완료 주문이 있어 삭제할 수 없습니다" |
| 완료된 주문만 존재 | ✓ 가능 | 주문 내역에서 '삭제된 상품' 표시 |
| 어떤 주문도 없음 | ✓ 가능 | 즉시 삭제 |

---

## 삭제 플로우

```
1. 삭제 버튼 클릭
2. 삭제 가능 여부 확인 (API 호출)
3. 확인 모달 표시
   - 삭제 가능: "정말 삭제하시겠습니까?"
   - 삭제 불가: "미완료 주문이 있어 삭제할 수 없습니다"
4. 확인 시 Soft Delete 실행
5. 목록에서 제거 (또는 '삭제됨' 표시)
```

---

## API 명세

### DELETE /api/v1/admin/products/{id}

**Response (성공)**

```json
{
  "id": "uuid",
  "is_deleted": true,
  "deleted_at": "2025-12-22T16:00:00Z"
}
```

**Response (실패 - 미완료 주문 존재)**

```json
{
  "error": "PENDING_ORDERS_EXIST",
  "message": "미완료 주문이 있어 삭제할 수 없습니다",
  "pending_order_count": 3
}
```

### PATCH /api/v1/admin/products/{id}/restore

**복구 API**

```json
{
  "id": "uuid",
  "is_deleted": false,
  "restored_at": "2025-12-22T17:00:00Z"
}
```

## 삭제된 상품 처리

### 장바구니
- 삭제된 상품: "품절" 또는 "판매 종료" 표시
- 결제 진행 불가

### 주문 내역
- 삭제된 상품: 상품명 옆에 "(삭제됨)" 표시
- 상품 상세 페이지 링크 비활성화

### 검색/목록
- 삭제된 상품은 노출되지 않음
- Admin에서는 필터로 조회 가능

---

## Admin 삭제 상품 관리

### 필터 옵션
- 전체 상품
- 활성 상품
- 삭제된 상품

### 삭제된 상품 목록
- 상품명, 삭제일시, 삭제자 표시
- 복구 버튼 제공

---

## 영구 삭제 (Post-MVP)

향후 구현 예정:
- 삭제 후 30일 경과 시 영구 삭제 옵션
- 영구 삭제 시 관련 이미지(R2)도 삭제
- 복구 불가 경고
