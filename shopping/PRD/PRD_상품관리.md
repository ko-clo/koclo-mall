#### 요구사항

- 상품 상세 페이지는 검색 엔진에 최적화되어야 한다.
- 상품별로 고유한 URL을 가져야 한다.
- 메타 정보(제목, 설명, 이미지)가 포함되어야 한다.

### 3.4 에러 처리

## 4. PRD-003 상품 등록

> **하위 목차**

| 항목 | 내용 |
|------|------|
| 기능 ID | PRD-003 |
| 기능명 | 상품 등록 (Admin) |
| 사용자 유형 | Admin |
| 우선순위 | P0 (MVP 필수) |

### 4.1 입력 정보

#### 기본 정보

| 필드 | 필수 | 설명 |
|------|------|------|
| 상품명 | Y | 2~100자 |
| 카테고리 | Y | 대분류 → 소분류 선택 |
| 간략 설명 | N | 최대 200자, 목록에서 표시 |
| 상세 설명 | N | 에디터로 작성 (기본 서식만) |
| 상태 | Y | 임시저장/판매중/판매중지 |

#### SEO 정보

| 필드 | 필수 | 설명 |
|------|------|------|
| SEO 타이틀 | N | 최대 70자, 미입력 시 상품명 사용 |
| SEO 설명 | N | 최대 160자, 미입력 시 간략 설명 사용 |

### 4.2 이미지 관리

#### 요구사항

- 대표 이미지 1장은 필수이다.
- 추가 이미지는 최대 10장까지 등록 가능하다.
- 드래그로 이미지 순서를 변경할 수 있다.

#### 이미지 규격

| 항목 | 규격 |
|------|------|
| 파일 형식 | JPG, PNG, WebP |
| 파일 크기 | 최대 5MB |
| 권장 크기 | 1200x1200px |

### 4.3 옵션 및 재고

#### 요구사항

- 색상과 사이즈 조합으로 옵션을 생성한다.
- 각 옵션별로 재고 수량을 관리한다.
- 옵션별 추가금액을 설정할 수 있다.

#### 옵션 구조

```mermaid
flowchart TB
    subgraph Product["상품"]
        Name["캐시미어 니트"]
    end

    subgraph Options["옵션 (색상 x 사이즈)"]
        O1["Black / S - 재고 10개"]
        O2["Black / M - 재고 15개"]
        O3["Black / L - 재고 5개"]
        O4["White / S - 재고 8개"]
        O5["White / M - 재고 12개"]
        O6["White / L - 품절"]
    end

    Product --> Options
```

### 4.4 가격 설정

| 필드 | 필수 | 설명 |
|------|------|------|
| 정가 | Y | 1,000원 이상 |
| 할인가 | N | 직접 입력 또는 할인율로 자동 계산 |
| 할인율 | N | 1~99%, 할인가 입력 시 자동 계산 |

#### 할인가 계산

- 할인율 입력 시 할인가 자동 계산
- 할인가 입력 시 할인율 자동 계산
- 5,000원 단위로 반올림

### 4.5 상품 상태

```mermaid
stateDiagram-v2
    [*] --> DRAFT: 상품 등록

    DRAFT --> ACTIVE: 공개
    DRAFT --> INACTIVE: 비공개 저장

    ACTIVE --> INACTIVE: 판매 중지
    INACTIVE --> ACTIVE: 재판매
```

| 상태 | 설명 |
|------|------|
| 임시저장 (DRAFT) | 등록 중, 고객에게 미노출 |
| 판매중 (ACTIVE) | 정상 판매, 고객에게 노출 |
| 판매중지 (INACTIVE) | 판매 중단, 고객에게 미노출 |

### 5.1 수정 가능 항목

PRD-003(상품 등록)과 동일한 모든 필드 수정 가능:
- 기본 정보 (상품명, 카테고리, 설명, 상태)
- 이미지 (추가/삭제/순서변경)
- 옵션/재고 (색상, 사이즈, 재고, 추가금액)
- 가격 (정가, 할인가, 할인율)
- SEO (타이틀, 설명)

### 5.2 주의사항

#### SKU 변경

| 상황 | 처리 |
|------|------|
| SKU 변경 시 | 경고 메시지 표시 |
| 경고 내용 | "SKU 변경 시 Midas ERP 동기화에 문제가 발생할 수 있습니다" |

| 조건 | 처리 |
|------|------|
| 장바구니에 해당 옵션 존재 | 삭제 불가, 안내 메시지 |
| 미완료 주문에 해당 옵션 존재 | 삭제 불가, 안내 메시지 |
| 완료된 주문만 존재 | 삭제 가능 |

| 항목 | 내용 |

### 6.1 삭제 정책

| 조건 | 삭제 가능 | 처리 |
|------|----------|------|
| 장바구니에 있는 상품 | 가능 | 장바구니에서 '품절' 표시 |
| 미완료 주문 존재 | 불가 | "미완료 주문이 있어 삭제할 수 없습니다" |
| 완료된 주문만 존재 | 가능 | 주문 내역에서 '삭제된 상품' 표시 |
| 주문 없음 | 가능 | 즉시 삭제 |

### 6.2 삭제 프로세스

```mermaid
flowchart TB
    A[삭제 버튼 클릭] --> B{미완료 주문?}
    B -->|있음| C[삭제 불가 안내]
    B -->|없음| D[삭제 확인 모달]
    D --> E{확인?}
    E -->|취소| F[종료]
    E -->|확인| G[삭제 처리]
    G --> H[목록에서 제거]
```

### 6.3 삭제 후 처리

| 영역 | 처리 |
|------|------|
| 장바구니 | "품절" 또는 "판매 종료" 표시, 결제 불가 |
| 주문 내역 | 상품명 옆에 "(삭제됨)" 표시, 링크 비활성화 |
| 검색/목록 | 노출되지 않음 |
| 관리자 | 삭제 필터로 조회 가능, 복구 가능 |

### 7.1 재고 동기화

```mermaid
flowchart LR
    subgraph Midas["Midas ERP"]
        Source["재고 원천<br/>(Source of Truth)"]
    end

    subgraph Shop["쇼핑몰"]

    end

    Source -->|"엑셀 업로드<br/>(단방향)"| Target
```

> **주의**: Midas ERP가 재고의 원천입니다. 쇼핑몰에서 개별 수정한 재고는 다음 Midas 동기화 시 덮어씌워집니다.

### 7.2 재고 조회

#### 표시 항목

| 컬럼 | 설명 |
|------|------|
| 상품명 | 상품명 + 썸네일 |
| SKU | 재고관리코드 |
| 색상/사이즈 | 옵션 정보 |
| 현재 재고 | 현재 재고 수량 |
| 상태 | 정상 / 저재고 / 품절 |
| 최종 수정 | 마지막 수정 일시 |

#### 필터/정렬 옵션

- 재고 상태 (전체 / 정상 / 저재고 / 품절)
- 카테고리별 필터
- 검색 (상품명, SKU)

### 8.1 카테고리 구조

2단계 계층 구조 (대분류 → 소분류)

```
대분류 (Parent)
├── 소분류 1 (Child)
├── 소분류 2 (Child)
└── 소분류 3 (Child)
```

#### 구조 예시

| 대분류 | 소분류 |
|--------|--------|
| 아우터 | 코트, 자켓, 패딩 |
| 상의 | 니트, 셔츠, 티셔츠 |
| 하의 | 팬츠, 스커트, 청바지 |
| 원피스 | 미니, 미디, 롱 |

### 8.2 기능 목록

| 기능 | 설명 |
|------|------|
| 카테고리 목록 | 트리 구조로 전체 카테고리 표시 |
| 카테고리 추가 | 대분류/소분류 생성 |
| 카테고리 수정 | 이름, 상위 카테고리 변경 |
| 카테고리 삭제 | 하위/상품 없는 경우만 가능 |
| 순서 관리 | 드래그앤드롭으로 정렬 순서 변경 |

#### 카테고리 추가/수정

| 필드 | 필수 | 설명 |
|------|------|------|
| 카테고리명 | Y | 2~50자 |
| 상위 카테고리 | N | 없으면 대분류로 생성 |
| 활성화 | Y | 비활성 시 고객에게 미노출 |

### 8.3 삭제 정책

| 조건 | 삭제 가능 | 안내 메시지 |
|------|----------|-------------|

| 연결된 상품 존재 | 불가 | "해당 카테고리에 N개 상품이 있습니다" |
| 빈 카테고리 | 가능 | 확인 후 삭제 |
