## 카테고리 구조

### 2-Depth 계층 구조

```
대분류 (Parent)
├── 소분류 1 (Child)
├── 소분류 2 (Child)
└── 소분류 3 (Child)
```

### 구조 예시

| 대분류 | 소분류 | 슬러그 |
|--------|--------|--------|
| 아우터 | 코트 | outer/coat |
| 아우터 | 자켓 | outer/jacket |
| 아우터 | 패딩 | outer/padding |
| 상의 | 니트 | top/knit |
| 상의 | 셔츠 | top/shirt |
| 상의 | 티셔츠 | top/tshirt |
| 하의 | 팬츠 | bottom/pants |
| 하의 | 스커트 | bottom/skirt |
| 하의 | 청바지 | bottom/jeans |

## 슬러그 자동 생성

```javascript
// 슬러그 생성 규칙
function generateSlug(name, parentSlug) {
  const slug = name
    .toLowerCase()
    .replace(/[^a-z0-9가-힣]/g, '-')
    .replace(/-+/g, '-')
    .replace(/^-|-$/g, '');
  
  return parentSlug ? `${parentSlug}/${slug}` : slug;
}

// 예시
// 대분류: "아우터" → "outer"
// 소분류: "코트" (부모: outer) → "outer/coat"
```

## API 명세

### GET /api/v1/categories

**전체 카테고리 트리 조회**

```json
{
  "categories": [
    {
      "id": "uuid",
      "name": "아우터",
      "slug": "outer",
      "parent_id": null,
      "sort_order": 1,
      "is_active": true,
      "product_count": 25,
      "children": [
        {
          "id": "uuid",
          "name": "코트",
          "slug": "outer/coat",
          "parent_id": "parent-uuid",
          "sort_order": 1,
          "is_active": true,
          "product_count": 12
        }
      ]
    }
  ]
}
```

### POST /api/v1/admin/categories

**카테고리 생성**

```json
{
  "name": "니트",
  "slug": "top/knit",
  "parent_id": "parent-uuid",
  "is_active": true
}
```

### PUT /api/v1/admin/categories/{id}

**카테고리 수정**

```json
{
  "name": "니트웨어",
  "slug": "top/knitwear",
  "is_active": true
}
```

### DELETE /api/v1/admin/categories/{id}

**카테고리 삭제**

성공 시: 204 No Content

실패 시:
```json
{
  "error": "HAS_CHILDREN",
  "message": "하위 카테고리가 있어 삭제할 수 없습니다",
  "children_count": 3
}
```

### PATCH /api/v1/admin/categories/reorder

**순서 변경**

```json
{
  "orders": [
    { "id": "uuid-1", "sort_order": 1 },
    { "id": "uuid-2", "sort_order": 2 },
    { "id": "uuid-3", "sort_order": 3 }
  ]
}
```

## 데이터 모델

### categories 테이블

| 컬럼 | 타입 | 설명 |
|------|------|------|
| id | UUID | PK |
| parent_id | UUID | 상위 카테고리 (NULL이면 대분류) |
| name | VARCHAR(50) | 카테고리명 |
| slug | VARCHAR(100) | URL 슬러그 (UNIQUE) |
| sort_order | INTEGER | 정렬 순서 |
| is_active | BOOLEAN | 활성화 여부 |
| created_at | TIMESTAMPTZ | 생성일시 |
| updated_at | TIMESTAMPTZ | 수정일시 |
